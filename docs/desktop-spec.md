# 桌面端规格（冻结 · 不实现）

> 本文件仅为规格保留。**当前不开发电脑端**，不产出任何桌面端代码。

## 定位

电脑端录入程序用于住宿高中生**回家后**的批量完善场景，与 Android 单机 MVP 通过 ExportBundle 交换数据。

## 职责

1. **导入 ExportBundle**。
2. 回家拍照录入：
   - SJ 原题；
   - 第一次做题痕迹；
   - 红笔改错；
   - BJ 页码。
3. 生成完善 PDF。
4. OCR 可选插件。
5. 冲突按 `updatedAt + deviceId` 解决。
6. AI 清洗需二次确认。

## 边界

- 不实现。
- 不做登录云同步。
- 不引入重型编辑器。
